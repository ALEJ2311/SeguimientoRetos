# Evidencias de Seguimiento de Retos

Autor: Jesus Rivas. Asignatura: Ingeniería Web.

El informe de 19 páginas documenta las evidencias 1 a 5 de la guía de frontend y la funcionalidad propia Plan de recuperación. Incluye backend y pruebas, compilación web, seguimiento semanal, aplicación Android, cierre con alertas y recuperación de una semana incumplida mediante acciones compartidas entre web y Android.

La compilación terminó correctamente con una advertencia de tamaño del paquete inicial de 1,21 MB. Las capturas Android se obtuvieron con la función de captura del emulador y no contienen el puntero del escritorio.

Las fechas y el porcentaje del reto utilizado en las simulaciones de la evidencia 5 se restablecieron después de las pruebas. El nuevo reto Lectura por recuperar se conserva como demostración: su semana original permanece al 5 % y cerrada, mientras el plan independiente se completó al 100 %. Las capturas muestran acciones guardadas desde web y Android y el resultado consultado en ambas interfaces.
